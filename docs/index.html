The Two-Stage Subdomain Lifecycle

Eliminate guesswork by separating DNS/SSL verification from backend application deployment.

1 Level 1: The Smoke Probe

Probe & Verify SSL

Injects a native Caddy static_response handler. Requires zero ports, zero files, and zero Node processes. Caddy contacts Let's Encrypt to auto-provision your TLS certificate.

# Verify DNS + SSL:
npx caddy-subdomain probe call.keshavsoft.com --reload
Proves: DNS reached server & HTTPS certificate issued.
2 Level 2: The Promotion

Connect Your Backend or Static Root

Now that the network pipe and SSL certificate are mathematically proven live, seamlessly promote the subdomain to a reverse proxy or static file server.

# Option A (Reverse Proxy):
npx caddy-subdomain add call.keshavsoft.com 5000
# Option B (Static File Server):
npx caddy-subdomain static call.keshavsoft.com /usr/share/caddy/call
Seamless: Overwrites probe with reverse_proxy (zero downtime).

Programmatic ESM Library

Use caddy-subdomain directly in your Node.js automation scripts and microservices.

// 1. Import from caddy-subdomain
import { 
  readCaddyConfig, 
  hasSubdomain, 
  addProbeSubdomainToFile, 
  addSubdomainToFile,
  addStaticSubdomainToFile
} from "caddy-subdomain";
// 2. Level 1: Add Probe to verify DNS & SSL
const probe = addProbeSubdomainToFile("/etc/caddy/caddy.json", {
  domain: "call.keshavsoft.com",
  backup: true
});
console.log(`Probe backup created at: ${probe.backupFile}`);
// 3. Level 2A: Promote probe route to reverse proxy backend port
const live = addSubdomainToFile("/etc/caddy/caddy.json", {
  domain: "call.keshavsoft.com",
  port: 5000,
  force: true, // Overwrites probe with reverse proxy
  backup: true
});
console.log(`Subdomain live at route index: ${live.routeIndex}`);
// 3. Level 2B: Promote probe route to static file server document root
const staticSite = addStaticSubdomainToFile("/etc/caddy/caddy.json", {
  domain: "call.keshavsoft.com",
  root: "/usr/share/caddy/call.keshavsoft.com",
  force: true, // Overwrites probe with static file_server
  backup: true
});
console.log(`Static site live at: ${staticSite.filePath}`);
