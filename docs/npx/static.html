Why Static File Server?

Not every subdomain requires a long-running Node.js or Docker backend process. For client-side single page apps, marketing landing pages, and documentation portals, Caddy's built-in file_server handler provides ultra-fast static file delivery directly with gzip/zstd compression.

Running npx caddy-subdomain static call.keshavsoft.com leverages caddy-template to inject the exact production-grade vars and file_server route matching standard VPS configurations (such as cli.keshavsoft.com).

Usage Variations

# 1. Default Document Root (/usr/share/caddy/<domain>)
npx caddy-subdomain static call.keshavsoft.com
# 2. Custom Document Root
npx caddy-subdomain static call.keshavsoft.com /var/www/call.keshavsoft.com
# 3. Via 'add' command (auto-detects path)
npx caddy-subdomain add call.keshavsoft.com /usr/share/caddy/call.keshavsoft.com
