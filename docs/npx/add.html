Level 2 • Backend Promotion

npx caddy-subdomain add

Connect your subdomain to your Node.js, Python, or Docker application port. Seamlessly replaces your Level-1 probe with zero downtime and automatic backup.

Live Production Syntax:
npx caddy-subdomain add call.keshavsoft.com 5000 /etc/caddy/caddy.json --force --reload

The Problem & Story

Once you have completed your Level 1 Flight Check with probe, your domain already has an active, valid TLS certificate issued by Let's Encrypt, and traffic is successfully flowing through Caddy.

Now, you start your Node.js server (e.g. listening on port 5000).

The Solution: Run add <domain> <port> --force --reload! The --force flag automatically replaces the static probe route with a reverse proxy forwarding all traffic to localhost:5000. Because Caddy hot-reloads in memory, active SSL sessions are preserved without dropping a single connection.

Under The Hood: Generated Reverse Proxy Route 

{
  "match": [{ "host": ["call.keshavsoft.com"] }],
  "handle": [
    {
      "handler": "subroute",
      "routes": [
        {
          "handle": [
            {
              "handler": "reverse_proxy",
              "upstreams": [{ "dial": "localhost:5000" }]
            }
          ]
        }
      ]
    }
  ],
  "terminal": true
}

Supported Options & Flags

Flag Type Description
--force Boolean Essential for promotion: Replaces existing domain route (such as Level-1 probe) with the new reverse proxy.
--reload Boolean Triggers zero-downtime hot-reload with caddy reload --config <file>.
--no-backup Boolean Skips saving the timestamped .bak.<timestamp> file.
