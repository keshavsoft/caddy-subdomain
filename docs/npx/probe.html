100% Automatic • Zero Configuration Required

npx caddy-subdomain probe

One single command to verify GoDaddy DNS propagation and auto-provision Let's Encrypt / ZeroSSL HTTPS. Auto-detects Caddy config, auto-reloads, and gives an instant Yes/No status.

Simple NPX Command: auto-detects /etc/caddy/caddy.json & auto-reloads
npx caddy-subdomain probe call.keshavsoft.com
Instant Yes / No Terminal Response
Subdomain: call.keshavsoft.com
Present in Caddy: Yes (Probe Active)
Caddy Reload: Success
Live HTTPS: Yes (200 OK - Verified)

Why It's 100% Automatic

Auto-Config

You never pass file paths from outside. It automatically discovers /etc/caddy/caddy.json on your VPS or ./caddy.json locally.

Auto-Reload

No --reload flag required. It hot-reloads Caddy in memory with zero downtime and preserves existing TLS connections.

Yes / No Verdict

Immediately tells you if the domain is present in Caddy and whether live HTTPS traffic reaches the server.

Under The Hood: Injected Static Response

Zero ports and zero processes needed. Caddy responds natively with 200 OK and auto-issues certificates:

{
  "match": [{ "host": ["call.keshavsoft.com"] }],
  "handle": [
    {
      "handler": "static_response",
      "status_code": 200,
      "headers": { "Content-Type": ["text/plain; charset=utf-8"] },
      "body": "✅ Subdomain 'call.keshavsoft.com' is LIVE on Caddy!\nDNS propagation and Automatic HTTPS (SSL) verified successfully.\n"
    }
  ],
  "terminal": true
}
