The NPX Command Catalog

Every command in caddy-subdomain is designed around a single responsibility in the subdomain lifecycle. Select a command below to explore its dedicated guide, options, and live workflow.

Level 1: Smoke Test

probe <domain>

Verify GoDaddy DNS propagation and Let's Encrypt SSL issuance without starting Node.js or allocating backend ports. Injects a native 200 OK static response.

npx caddy-subdomain probe call.keshavsoft.com --reload
Level 2: Backend Promotion

add <domain> <port>

Connect your verified subdomain to your Node.js / Python / Docker backend port. Seamlessly replaces the Level-1 probe with zero downtime and automatic backup.

npx caddy-subdomain add call.keshavsoft.com 5000 --force --reload
Observability

list [configPath]

Extract and index every active subdomain currently listening across all HTTP servers in your Caddy configuration. Zero JSON scrolling needed.

npx caddy-subdomain list /etc/caddy/caddy.json
Collision Guard

check <domain>

Pre-flight collision verification. Confirms whether a subdomain is available to be registered or already active on the server before mutating files.

npx caddy-subdomain check quotation.keshavsoft.com
