npx caddy-subdomain check

Ask one question: Is this subdomain present in Caddy? Returns an instant Yes or No. No config paths needed.

Simple NPX Command: auto-detects /etc/caddy/caddy.json
npx caddy-subdomain check call.keshavsoft.com
Output: Pure Binary Verdict
If Subdomain Exists:
Subdomain: call.keshavsoft.com
Present in Caddy: Yes
If Subdomain Not Found:
Subdomain: call.keshavsoft.com
Present in Caddy: No

Zero Guesswork Pre-flight

Before creating routes, deploying code, or debugging connections, run check <domain>.

  • Zero arguments needed: Automatically finds Caddy's configuration file.
  • Exit code aware: Returns exit code 0 if present, and 1 if absent (perfect for shell scripts and CI/CD).
  • Case-insensitive: Matches regardless of casing.
