Observability • Subdomain Inventory

npx caddy-subdomain list

Print an indexed inventory of every unique subdomain configured across all HTTP servers in your Caddy JSON without manually reading through hundreds of nested lines.

Live Production Syntax:
npx caddy-subdomain list /etc/caddy/caddy.json

The Problem & Story

On a production VPS running multiple microservices, Caddy's configuration file grows rapidly into hundreds or thousands of lines of nested JSON: apps ➔ http ➔ servers ➔ srv0 ➔ routes ➔ match ➔ host.

Finding out which domains are currently active or verifying that a newly added subdomain successfully registered can be tedious.

The Solution: Run list! It inspects all HTTP servers, deduplicates hostnames, and outputs a clean, indexed summary in under 50ms.
